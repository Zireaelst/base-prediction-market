# Swipe Discovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver live category-based discovery and an accessible swipe deck that records an explicitly confirmed, reasoned free forecast in an owner-only personal space or a selected joined room.

**Architecture:** Extend the existing Next.js/SQLite application rather than introducing another backend. A server-only Limitless market-page adapter owns category resolution, normalization and freshness; a single authenticated forecast API owns destination authorization; Explore list and swipe share the same category pagination hook. The coordinator owns shared contracts and cross-slice integration.

**Tech Stack:** Next.js 15, React 19, TypeScript, better-sqlite3, Vitest, existing CSS/Geist font tokens, public Limitless REST API.

## Global Constraints

- Application baseline `0ae4c7506ebc02d480ea73521acde77c3feff132`; approved design `docs/superpowers/specs/2026-10-30-swipe-discovery-design.md` at `e2b1809`. Separate pinned research source `b1167defe82afd37f1eeda31d6e8b1350c462943`.
- No paid services, real-money orders, mainnet writes, contracts, custody, replacement AMM/oracle or public deployment. Do not misrepresent free forecasts or existing paper simulation as venue trades.
- Only Base Sepolia chain ID 84532 is authorized for any necessary onchain writes; this feature has none. Preserve existing SIWE verification.
- Outcomes always use original venue token IDs and accurate mapped labels; binary-only cards omit groups and ambiguous mappings. Stale data cannot be submitted. Keep venue prices non-executable and optional on swipe cards.
- Keep Geist Pixel / ASCII-dither black-off-white-lavender design, mobile native scrolling, keyboard support, reduced-motion/static fallback. AXON attachment unavailable; no visual-fidelity claim.
- Worker handoff: changed paths, tests/smoke output, remaining risks; no worker runs builds/lint/formatters concurrently. Coordinator runs integrated checks once after all edits. At most 3 concurrent workers, no shared-file editing.
